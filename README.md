# Java-merging-arrays
A program that performs the following operations:
• Creates and populates two arrays, a and b, with integers. The number of elements and their values are entered via
the keyboard (first enter the number of elements and values for array a, then the number of elements and
values for array b)
• Prints the elements of array a to the screen (on a single line, separated by spaces)
• Prints the elements of array b to the screen (on a single line, separated by spaces)
• Checks whether the elements of arrays a and b are sorted in ascending order. If the elements of array a or
the elements of array b are not sorted in ascending order, display the message “invalid input data” and terminate
the program
• Copies the numbers from arrays a and b into array c in such a way that the numbers in array c are also sorted in ascending
order. The program does not use nested loops or array sorting methods
• Displays the message “result:” on the screen, and then, on a new line, displays the elements of the array c (on a single line,
separated by spaces)
